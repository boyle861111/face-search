# FaceSearch 照片人臉辨識

上傳少量目標人物照片，從大量照片中找出含有該人物的照片。單機執行，資料不外傳。

- 下載：Releases 頁面的 `FaceSearch.zip`（或 GitHub Actions 打包結果），解壓縮後執行 `FaceSearch.exe`
- 視窗標題會顯示版本號，回報問題時請一併提供
- 模型：InsightFace buffalo_l（僅限非商業用途）

## 使用步驟

1. 第一次使用按「建立目標資料夾」，程式會建立 `目標\人名1` 範例資料夾並開啟。
2. 把要找的人的照片放進去，資料夾改成他的名字。要找多個人就每人一個子資料夾。
3. 「照片資料夾」選擇要搜尋的照片所在位置（會包含所有子資料夾），按「開始搜尋」。
4. 找到的照片會「複製」到輸出資料夾（原始照片不會被更動），完成後可選擇開啟結果資料夾。

## 目標資料夾結構

```
目標\
  王小明\  照片1.jpg  照片2.jpg  照片3.jpg
  陳小華\  照片1.jpg  照片2.jpg
```

- 每人建議 3～10 張清楚、不同角度的照片；少於 3 張時程式會提醒準確度可能較低。
- 照片裡有多張臉時，程式會自動挑與其他樣本最像的那張臉；最好多放幾張只有本人的照片。
- 子資料夾內沒有照片、或全部偵測不到臉時，會在訊息區顯示「無可用樣本，已略過」。
- 如果目標資料夾直接放照片（沒有人名子資料夾），會把整個資料夾當作同一位目標。

## 支援格式

jpg / jpeg / png / bmp / webp，以及 iPhone 的 heic / heif。

## 設定說明

| 設定 | 說明 | 建議值 |
|---|---|---|
| 相似度門檻 | 越高越嚴格、誤判越少，但可能漏掉角度不同的照片 | 0.45～0.55（預設 0.50）。找不到人時調低，誤判太多時調高 |
| 偵測解析度 | 越高越能找到照片中較小的臉，但較慢 | 一般照片 640；團體照、遠景 1024～1280 |
| 輸出邊緣照片 | 相似度略低於門檻（差 0.10 以內）的照片另存「邊緣」資料夾，供人工確認 | 開啟 |
| 使用 GPU | 使用顯示卡加速（DirectML）。無法使用時會自動改用 CPU 並提示 | 開啟 |

結果清單可點欄位標題排序，也可在「顯示目標」選擇只看某一個人；雙擊可開啟照片。

## 輸出結果

輸出資料夾內每次搜尋建立一個時間命名的資料夾：`結果\20261117_093000\人名\命中（或邊緣）\`，並附 `results.csv` 清單。

## 快取、設定檔與錯誤紀錄

- `faces.db`：照片分析結果快取。同一張照片沒有變動時不會重新分析，第二次搜尋會快很多。
  - 讀取失敗的照片不會被快取，下次會重新嘗試。
  - 每次完整搜尋後，會自動清除該照片資料夾中已刪除照片的紀錄。
  - 想完全重新分析，可以關閉程式後刪除 `faces.db`。
- `settings.json`：上次使用的資料夾與設定。
- `face_search.log`：發生錯誤時的詳細紀錄，回報問題時請附上。
- 以上檔案預設放在 `FaceSearch.exe` 旁邊；若該位置不能寫入（例如放在 Program Files），會改放在 `%LOCALAPPDATA%\FaceSearch`。

## 開發者

- 打包：GitHub Actions `Build Windows EXE`（手動執行或推送 `v*` 標籤）。套件版本固定在 `.github/workflows/build.yml`。
- 打包後會以 `FaceSearch.exe --selftest` 無介面載入模型自我測試。
